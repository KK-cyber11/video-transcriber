# 视频转逐字稿（轻量版）

## 它做什么
输入一条抖音或小红书公开视频链接，或一个本地视频/音频文件，输出一份简体中文 Markdown 逐字稿：
1. 获取视频：抖音先用游客身份读取官方网页接口（校验视频 ID，只下载音轨）；其他情况用 yt-dlp；失败时用全新的无痕浏览器像普通访客一样打开公开页面，取它播放的音视频流；小红书直接读取公开分享页自带的笔记数据。
2. 用 faster-whisper 在本机转写（CPU 即可，默认 small 模型，语言中文）。
3. 用 OpenCC 统一转成简体。

## 一次性安装（每台机器只需一次）
```bash
sh scripts/setup.sh
```
有 `uv` 会优先用 uv，否则用系统 `python3`（需 3.10+）。会下载 Python 依赖和 Playwright Chromium（约几百 MB）；第一次转写还会下载 whisper 模型（small 约 500MB）。

## 使用
```bash
scripts/v2md "<抖音或小红书链接>"            # 输出到 ./transcripts/
scripts/v2md /path/to/video.mp4 --title "标题" --author "作者" --url "原链接"
scripts/v2md "<链接>" --out ~/Notes/逐字稿 --model medium
scripts/v2md "<链接>" --glossary scripts/glossary.txt   # 可选：术语提示
```
需要用画面字幕核对【存疑】时，请改用「video-transcriber-frames」版本。
```
```
- 可以直接粘贴 App 里「分享 → 复制链接」得到的链接（如 `v.douyin.com/...`、`xhslink.com/...`、`xhslink.cn/...`）；如果用户粘贴的是整段分享文案，先从中提取出 http 链接再传入。
- 运行成功后最后一行打印生成的 md 文件路径。把它读出来给用户看。
- 一条 3～4 分钟的视频在普通 CPU 上大约 1～3 分钟；长视频更久，请耐心等待，不要中途重复运行。

## 输出格式
文件名：`<日期>-<标题>.md`，内容：
- 标题、作者、来源链接、发布日期、时长、转写说明（取不到的字段写「未知」，绝不编造）
- 小红书会附上笔记正文
- `## 校对版`、`## 修改记录`：由 AI 助手校对后填写
- `## 带时间戳原文`：每句前带 `[时:分:秒]`，机器原文，不改动
- 小红书图文笔记（没有视频）会只保存正文

## 必做：校对（由你这个 AI 助手完成，不需要任何 API key）
v2md 输出**一个** md 文件，结构固定：头部信息 → `## 校对版` → `## 修改记录` → `## 带时间戳原文`。
跑完后你**必须**在**同一个文件**里完成校对（不要另建文件）：
1. 读取 md。`## 带时间戳原文` 一个字都不要改。
2. 用你的校对稿替换 `## 校对版` 下的占位文字：根据上下文、标题、正文/描述、话题标签、领域常识，修正同音字和识别错误（如「机药→纪要」「支持库→知识库」「Cloud Code→Claude Code」），补全标点、按意思分段。
3. 在 `## 修改记录` 表格里每处修改写一行：`| 时间 | 原文 | 改为 | 理由 |`。
4. 把头部的 `- 校对：未校对` 改成 `- 校对：AI 校对，已修正 N 处，存疑 M 处`。
5. 铁律：
   - **只改识别错误，不增、不删、不润色、不改写观点**；口语保留。
   - 没把握的地方，在正文写成 `【存疑：原文“X”】`（可附“疑为Y”），修改记录里也标【存疑】。宁可存疑，不要猜成确定。
   - 数字、人名、品牌只在有依据时才改。


## 其他注意事项
- 视频里的数据和说法不等于事实，必要时提醒用户核实。
- 如果用户常处理某一领域，可以把易错专有名词写进 `scripts/glossary.txt`，运行时加 `--glossary scripts/glossary.txt`，能减少一部分错字（不能替代校对）。
- 想更准可以用 `--model medium`（需要约 5GB 以上空闲内存）。

## 限制
- **抖音**：用匿名游客身份 + 移植的网页签名（a_bogus 等，来自 Evil0ctal/Douyin_TikTok_Download_API，Apache-2.0）读取视频详情，**并核对返回的视频 ID 与链接一致**才会转写；不一致或失败会报错停止，绝不转写别的视频。抖音改版签名后可能失效，届时请用户在 App 里保存视频后转写本地文件。
- 平台字幕：实测抖音、小红书公开页面都没有可直接读取的字幕/文字稿轨道，所以一律用本地语音识别。
- **不支持微信视频号**：视频号只能在微信里打开，脚本会直接提示。替代办法：在微信里把视频转发给官方「元宝」要逐字稿，或把视频保存到手机后用本工具转写本地文件。
- 只处理**公开**内容；私密、付费、需要登录才能看的内容会失败。
- 不登录、不读取浏览器 cookie、不使用任何人的账号，只用普通访客自动获得的游客 cookie；不绕过访问限制。平台页面改版后可能失效。
- 一次只处理一条链接；不支持批量抓取、主页下载、评论采集。
- 仅供个人学习、做笔记使用；请遵守各平台用户协议和版权，不要用于搬运或商用。
